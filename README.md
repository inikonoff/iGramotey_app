# iGramotey — плавающий виджет диктовки

Android-приложение: зажми виджет, надиктуй, отпусти. Текст распознаётся, исправляется на сервере и вставляется в поле ввода (а также остаётся в буфере обмена).

История изменений и причины правок: [CHANGELOG.md](CHANGELOG.md).

## Как пользоваться

| Действие | Что происходит |
|---|---|
| **Зажать** виджет (≈0,2 с) | Начинается запись |
| **Отпустить** | Запись уходит на сервер; результат вставляется в активное поле и копируется в буфер |
| **Перетащить** | Виджет двигается, начатая запись отменяется; позиция запоминается |
| **Двойной тап** | Выключить виджет |

Состояния виджета (скруглённый квадрат, цвет подложки показывает состояние):

| Состояние | Значок | Подложка |
|---|---|---|
| Ожидание | 🎤 | серая |
| Запись | 🎤 | красная |
| Обработка | ⏳ | тёмно-серая |
| Готово (3 с, затем снова ожидание) | ✅ | зелёная |

## Как это работает

```
микрофон → m4a (AudioRecorder) → POST /api/dictate → сервер:
   Groq Whisper (распознавание) → YandexGPT (правка «Красиво», с запасными моделями)
→ текст → буфер обмена + автовставка в поле ввода
```

Вся обработка на сервере [voice_bot](https://github.com/inikonoff/voice_bot), в APK нет ключей ИИ. Распознавание речи всегда на Groq; модель правки сервер выбирает сам (профиль `APP_LLM_PROFILE`, по умолчанию YandexGPT с откатом на бесплатные модели и Groq).

Запрос: `POST multipart/form-data`, поле `file`, заголовок `X-App-Token`. Ответ: `{"status": "success", "text": "..."}`.

## Права при первом запуске

- **Микрофон** — стандартный диалог.
- **Поверх других окон** — откроются настройки системы, включить вручную.
- **Автовставка** (необязательно) — включить «iGramotey — автовставка» в «Специальных возможностях». Без неё текст остаётся только в буфере обмена.

На Honor/MagicOS, если виджет пропадает в фоне: батарея → «Без ограничений» (или «Запуск вручную», все три переключателя) и разрешить автозапуск.

## Сборка

### В GitHub Actions (основной способ)

Workflow `.github/workflows/build-apk.yml` запускается на каждый push и вручную (*Actions → Build APK → Run workflow*). Он собирает debug и release APK и сохраняет их артефактами `igramotey-debug-apk` и `igramotey-release-apk`.

**Установка новой сборки поверх старой** требует постоянной подписи. Один раз добавьте секреты репозитория (*Settings → Secrets and variables → Actions*):

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | keystore в base64 (одной строкой) |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | алиас ключа |
| `KEY_PASSWORD` | пароль ключа |

Значения чистятся от пробелов и переводов строк, а ключ проверяется до сборки с понятным сообщением об ошибке. Без секретов CI подписывает APK одноразовым ключом: он установится, но обновить им приложение с другим ключом нельзя (придётся удалить старую версию). Не потеряйте keystore и пароли и не храните их в репозитории.

Версия растёт сама: `versionCode = 100 + номер запуска`, `versionName = 2.0.<номер запуска>`.

### Локально

В репозитории нет `gradle-wrapper.jar` (в исходном архиве он был пустым), поэтому `./gradlew` не работает. Собирайте в Android Studio или установленным Gradle 8.4:

```bash
gradle assembleDebug     # APK: app/build/outputs/apk/debug/
```

Адрес сервера и токен заданы в `app/build.gradle.kts`:

```kotlin
buildConfigField("String", "API_BASE_URL", "\"https://voicebot-iwdm.onrender.com\"")
buildConfigField("String", "APP_SECRET_TOKEN", "\"...\"")
```

Токен совпадает с переменной `APP_SECRET_TOKEN` на сервере.

## Архитектура

```
MainActivity.kt              — запрашивает права, запускает сервис и сворачивается
FloatingWidgetService.kt     — foreground-сервис: виджет, касания, запись, состояния
AudioRecorder.kt             — запись в m4a через MediaRecorder
ApiClient.kt                 — POST /api/dictate, разбор JSON
PasteAccessibilityService.kt — автовставка текста в активное поле
```

## Первый запрос после простоя

Бесплатный хостинг сервера засыпает без запросов, поэтому первая диктовка после долгого перерыва может идти около минуты. Решение на стороне сервера: внешний пингер на `/ping` раз в 10 минут.
