# Changelog

Здесь фиксируется каждое изменение: что сделано, **почему** и какие новые фичи появились.
Новые записи добавляются сверху. Формат: `Added` — новые фичи, `Changed` — изменения, `Fixed` — исправления (с причиной).

## [Unreleased]

### Added
- Установка каждой новой сборки поверх установленной.
  - `versionCode` в CI = `100 + номер запуска workflow`, `versionName` = `2.0.<номер запуска>`, поэтому каждая сборка новее предыдущей.
  - Debug и release подписываются одним и тем же ключом, чтобы ставились друг поверх друга.
  - Ключ хранится в секретах GitHub (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`), не в репозитории: репозиторий публичный.
- Release-сборка (`assembleRelease`, minify включён) в GitHub Actions; APK доступны как артефакты `igramotey-debug-apk` и `igramotey-release-apk`.
- Этот `CHANGELOG.md`.

### Changed
- Подложка под иконками виджета: круг 64 dp с белой обводкой. Причина: иконка (эмодзи без фона) терялась на пёстрых и светлых экранах. Цвет подложки показывает состояние: тёмная — ожидание, красная — запись, серая — обработка, зелёная — готово. Иконка 📋 получила такую же подложку и отступ от микрофона.

### Fixed
- **Сборка падала на `packageDebug`: «keystore password was incorrect».** Причина: пароль/ключ из секретов GitHub не совпал с реальным keystore — чаще всего из-за лишних пробела или перевода строки при вставке секрета. Теперь CI очищает значения секретов от пробелов и `\r\n` и сразу проверяет keystore через `keytool -list` с понятным сообщением об ошибке.
- **Виджет двигался рывками и тормозил.** Причины:
  1. Окно оверлея создавалось без `FLAG_HARDWARE_ACCELERATED`, поэтому цветной эмодзи рисовался программно (CPU) при каждом сдвиге. Флаг добавлен.
  2. Запись стартовала сразу на касании: каждое перетаскивание сначала синхронно запускало `MediaRecorder` на UI-потоке, а при первом движении останавливало его и удаляло файл — отсюда подвисание в начале жеста. Теперь запись стартует после удержания 180 мс без движения; сдвиг раньше этого отменяет старт.
  3. Порог перетаскивания был 18 px (около 6 dp на плотных экранах), дрожание пальца при удержании отменяло запись. Порог теперь 12 dp.
- **CI падал на шаге `setup-gradle`.** Причина: `gradle/wrapper/gradle-wrapper.jar` в присланном архиве был пустым (0 байт), валидация wrapper не проходила. Пустой jar удалён, Gradle 8.4 ставится в CI напрямую. Локально `./gradlew` без jar не работает — собирать через Android Studio или установленный Gradle 8.4.
- **Без секретов подписи обновление поверх невозможно.** Причина: в таком случае CI создаёт новый одноразовый ключ на каждой сборке, а Android не даёт обновлять приложение, подписанное другим ключом. Нужно один раз добавить секреты (см. выше).

## [2.0] — оверлей-версия (актуальная)

### Added
- Запись голоса по удержанию виджета: нажал и держишь — запись, отпустил — отправка на сервер.
- Иконка 📋 рядом с микрофоном: виджет следит за буфером обмена, по нажатию текст отправляется на `/api/correct` («Красиво») и вставляется обратно (`ApiClient.processText`).
- Запрос разрешения «поверх других приложений» (`SYSTEM_ALERT_WINDOW`) в `MainActivity`.

### Changed
- Отказ от Bubble API. Причина: решение владельца проекта; возвращён обычный оверлей через `FloatingWidgetService`.
- Перетаскивание виджета отменяет начатую запись (порог сдвига 18 px).

### Removed
- `BubbleActivity`, `BubbleManager`, `RecordingService`, запрос `POST_NOTIFICATIONS`.

## Начальная загрузка
- Проект dictate-widget импортирован в репозиторий (Bubble-версия). Из архива исключены `.idea/`, `build/`, `.gradle/`, `local.properties`.
